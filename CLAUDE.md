# РАЗГОН — трекер тренировок

Одностраничное приложение для 12-недельной силовой программы. Открывается с домашнего
экрана iPhone как PWA. Всё в одном файле: ни сборщика, ни зависимостей, ни бэкенда.

## Файлы

```
index.html    ← ЕДИНСТВЕННЫЙ источник. Все правки сюда.
check.mjs     ← проверки прогрессии и синхронизации, node check.mjs
```

Раньше `index.html` генерировался из `src/app.src.html` через `build.py`. Сборка была нужна,
пока приложение писалось внутри артефакта Claude: там доступен только `window.storage`,
а на телефоне — только `localStorage`. Эту развилку теперь решает шим `DB` в рантайме,
и вторая копия файла стала обузой. Сборки нет, `index.html` правится напрямую.

## Проверка перед коммитом

```bash
node check.mjs
sed -n '/<script>/,/<\/script>/p' index.html | sed '1d;$d' > /tmp/c.js && node --check /tmp/c.js
```

`check.mjs` выдирает `PLAN`, `suggest()` и `SYNC` прямо из `index.html` и прогоняет на них
сценарии — так ошибка в прогрессии видна сразу, а не на шестой неделе, где она визуально
никак себя не проявляет. Правки прогрессии или синхронизации проверять обязательно так.

Осторожно с обратными слэшами: правки через `bash -c` и `node -e` их теряют. Регулярки
в этом файле нарочно написаны без экранирования (`[^A-Za-z0-9+/=]` вместо `\s`) — не
«улучшать» обратно.

## Ограничения, которые нельзя нарушать

**Хост деплоя не меняется.** `localStorage` привязан к origin — схема, хост, порт. Путь
в origin не входит: переименование репозитория и, следом, пути на `github.io` лог не
затрагивает. Терять данные заставляет только смена хоста — свой домен, другой аккаунт,
переезд на Netlify. Если такой переезд неизбежен — сначала «Сохранить копию», потом
«Загрузить копию» на новом адресе, либо просто ввести токен и нажать «Взять из репо».

Следствие того же правила: все проекты на `mgavriluk.github.io` делят одно хранилище.
Ключи `cycle-state`, `gh-sync`, `cycle-mark` лежат в общем пространстве имён — появится
второе приложение на этом хосте, имена придётся разводить.

**Хранилище идёт через шим `DB`, а не напрямую.** Файл живёт в двух средах: внутри
артефактов Claude доступен только `window.storage` (там `localStorage` падает), автономно
на телефоне — наоборот. `DB.get/set` выбирает нужное. Прямые вызовы в обход шима
запрещены — кроме самого шима, где они и должны быть.

**Токен вписан в файл — сознательное решение владельца.** Константа `CFG` в `index.html`
держит `repo` и `token` для `cycle-data`. Репозиторий приложения публичный, значит после
пуша этот токен общедоступен и писать в `cycle-data` может любой. Владелец предупреждён
дважды и принял риск 2026-08-22; не переигрывать это решение и не вычищать токен без
его слова.

Практические следствия, которые из этого вытекают:

- Токен в `CFG` — расходник. Утёк, начались чужие коммиты в `cycle-data` — отозвать,
  выпустить новый, вписать, запушить. Права у него узкие (`Contents: read/write` на один
  приватный репо с данными), так что ущерб ограничен логом тренировок.
- Введённое в интерфейсе перекрывает `CFG`: `'gh-sync'` из хранилища читается первым,
  `CFG` подхватывается только когда там пусто. Поле для токена в интерфейсе остаётся —
  через него можно жить без токена в файле, если решение когда-нибудь пересмотрят.
- Единственный способ держать токен в файле и не публиковать его — приватный репозиторий
  приложения, а Pages из приватного требует GitHub Pro. Бесплатный деплой был исходным
  требованием, поэтому этот путь отклонён.

**Таймер отдыха считает от метки времени, а не тиками.** iOS усыпляет свёрнутое
приложение, и `setInterval` отстаёт. Хранится `cEnd` (момент окончания), остаток
пересчитывается как `cEnd - Date.now()`. Обработчик `visibilitychange` пересчитывает
при возврате. Не переписывать на счётчик.

**Звук в фоне не работает.** iOS глушит аудио у свёрнутых веб-приложений — обойти без
нативного приложения нельзя. Компенсируется Wake Lock: экран не гаснет, пока идёт отдых.
Не обещать пользователю фоновые уведомления.

**Хранение — только текст.** Никаких `<form>`.

## Модель данных

Один ключ состояния плюс настройки синхронизации:

```js
'cycle-state' = {
  week: 1..12,
  day: 0..3,
  log: { 'w3d0': { 0: { w: 70, s: [true,true,false], d: 'hard', n: '3,3,2' } } }
}
// w — вес, s — выполненные подходы, d — 'easy'|'ok'|'hard', n — заметка

'gh-sync'   = { repo: 'логин/приватный-репо', token: '...' }
'cycle-mark' = { at: 1755..., sent: 1755... }   // at — последняя локальная запись, sent — что уехало
```

Пустые записи вида `{w:null, s:[]}` создаются при листании недель вперёд. Мусор в экспорте,
но безобидный — не чинить.

Трекер белка (`'protein-day'`, `FOODS`, `drawP`) удалён 2026-08-20: за три недели остался
нулевым. Вместе с ним ушли `shiftDay()` и `GOAL`. Если понадобится дневник питания —
это отдельная задача, а не восстановление удалённого.

## Синхронизация

Бэкенда нет. Объект `SYNC` пишет одним PUT в приватный репозиторий через Contents API:

```
save() → MARK.at=сейчас → queuePush() → пауза 10 с → PUT contents/cycle.json → MARK.sent=at
pagehide / online / возврат в приложение → PUT немедленно, если MARK.at > MARK.sent
```

**Никакого TTL у локального хранилища.** Соблазн «пометить локальные данные просроченными
и перечитать из репо» ведёт к потере тренировки: локальное здесь источник правды, а не кеш
чужих данных. Записи рождаются в зале, часто без сети. Срок годности выбросил бы свежую
правду ради копии, которая заведомо старее. Рассинхрон решается сравнением метки, а не
сроком: `MARK.at > MARK.sent` значит «есть неотправленное».

Решения, которые выглядят странно, но нужны:

- **Пауза 10 секунд.** Тап по подходу вызывает `save()`. Без паузы это тридцать запросов
  за тренировку вместо одного.
- **`keepalive: true` на PUT.** Иначе запрос при сворачивании приложения не доживает
  до отправки, и последний подход теряется.
- **base64 через `TextEncoder`.** В заметках кириллица, `btoa()` её сам не переваривает.
  На чтении из base64 вычищаются любые не-base64 символы: GitHub отдаёт content с переносами.
- **Повтор при 409/422.** Устаревший `sha` — перечитать файл и записать поверх.
- **`const at=MARK.at` фиксируется до запроса.** Иначе отметка подхода, сделанная пока PUT
  в полёте, пометилась бы отправленной и потерялась. В `check.mjs` на это есть проверка.
- **Флаг не снимается при ошибке.** Сорванный пуш обязан остаться неотправленным, иначе
  тренировка исчезает тихо. Тоже под проверкой.
- **Догон по `online` и `visibilitychange`.** Без него пуш, сорванный в зале без связи,
  лежал бы до следующей отметки подхода.
- **Тянем из репо только когда `S.log` пуст.** Телефон — единственный источник правды,
  а пустой лог означает свежую установку или снесённое хранилище. Для двух устройств
  понадобится сверка по `at` (метка времени в payload уже пишется). Кнопка «Взять из репо»
  делает то же вручную и без условий.

Токен — fine-grained PAT с правами `Contents: read/write` ровно на один приватный репо
с данными. Лимит GitHub API 5000 запросов в час, расход — около десяти в неделю.

## Логика программы (не менять без причины)

Программа лечит конкретную проблему: бывший боксёр, много выносливости, мало максимальной
силы. Отсюда решения, которые иначе выглядят странно:

- **Диапазон 1–5 повторений на базе.** Гипертрофия здесь вторична, задача — научить
  нервную систему включаться разом. Не «улучшать» на 8–12.
- **Отдых 3–5 минут на базе** (`rest: 270`). Короче — тренируется выносливость, которой
  и так избыток. Таймер запускается автоматически после отмеченного подхода.
- **Автоприбавка веса только там, где задан `step`** — жим, присед, становая, жим стоя.
  У изоляции `step` отсутствует, `suggest()` переносит вес прошлой недели без изменений.
  Это не баг: +2,5 кг на блочном трицепсе — скачок на 17%. Там двойная прогрессия
  по повторениям, отсюда диапазоны вида `12–15` в поле `r`.
- **Откат при застое:** два провала подряд на одном весе → минус 7,5 кг.
- **Отмеченный подход фиксирует вес.** Подсказка `suggest()` показывается как placeholder;
  раньше она попадала в лог только если нажать ± или впечатать число, и 22 записи из 53
  остались без веса. Теперь отметка подхода сохраняет показанный вес. Прошлые дыры
  не заполнены — задним числом вес не угадать.
